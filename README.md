# OxMeter (OxLogic DMM)

**Professional On-Screen Digital Multimeter (DMM) Overlay for Smartphone & Electronics Repair**

---

### Overview

**OxMeter** is a specialized on-screen digital multimeter designed for **smartphone repair technicians, chip-level instructors, and YouTube/live-stream trainers**.

It allows technicians to display a fully functional, realistic digital multimeter right on top of schematics and boardviews (such as Borneo Schematics, ZXW, XinZhiZao, Pragmafix), showing real-time diode values, voltages, resistance, and continuity beeps during tutorials and online classes.

### Key Features

* **Realistic DMM Hardware Experience:** Authentic dial knob rotation with mechanical click sounds, 7-segment digital LCD readout with realistic digit flicker, and continuity beep buzzer.
* **Interactive Magnetic Probes:** Draggable Red and Black test probes that magnetically dock directly to the meter sockets when brought close.
* **Measurement Modes:**
  * **DCV** (DC Voltage: e.g., VPH_PWR `3.82V`, VREG `1.80V`)
  * **ACV** (AC Voltage)
  * **Ohm (Ω)** (Resistance: e.g., `10.2 Ω`, `4.70k`, `1.45M`)
  * **Diode** (Forward & Reverse Bias: `0.420`, `OL`, `0.002` Short)
  * **Continuity** (Short detection with real buzzer sound: `0.001` + Beep)
* **Global Hotkey Control:**
  * Switch presets on-the-fly while working inside any schematic software using `Numpad 1-9`, `Ctrl + 1-9`, or `Alt + 1-9`.
  * Instant clear to idle (`OL` / `0.000`) with `Numpad 0`, `Ctrl + 0`, or `Alt + 0`.
  * Windows chime suppression ensures silent hotkey triggering without annoying system beeps.
* **Live Preset Editor & Quick Actions:**
  * Built-in Control Panel to customize, add, edit, or delete presets on-the-fly.
  * Changing mode, name, or value in the editor immediately reflects on the multimeter in real-time.
* **Multi-Monitor Support:** Easily assign the overlay to primary or secondary displays.

### How to Run

1. Download **`OxMeter_v1.0.0_Portable.zip`** from the download link above.
2. Extract the ZIP file to any folder on your computer.
3. Double-click **`OxMeter.exe`** to start using the multimeter immediately.

### Hotkeys & Shortcuts Table

| Hotkey | Action | Description |
| :--- | :--- | :--- |
| **Numpad 1 - 9** | Measurement Presets | Trigger measurement preset for current slot |
| **Ctrl + 1 - 9** | Global Shortcut | Alternative global hotkey for preset slots |
| **Alt + 1 - 9** | Global Shortcut | Alternative global hotkey for preset slots |
| **Numpad 0 / Ctrl+0 / Alt+0** | Clear Reading | Reset display back to idle (`OL` / `0.000`) |
| **Spacebar** | Toggle Reading | Toggle active reading ON / OFF inside Control Panel |
| **Escape** | Idle Reset | Clear meter display back to idle state |
